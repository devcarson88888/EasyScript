Language guide

EasyScript

一门自制编程语言，提供调试解释执行与 AOT 编译两种运行方式。本文档介绍常用命令、基础语法和一个完整的 .es 示例。

Rust 实现 debug 解释执行 build AOT 编译 .es 源文件

项目介绍

EasyScript 将自定义语法解析后交由运行时执行，也可以通过 AOT 后端生成并编译目标程序。调试脚本使用 debug；将脚本编译为可执行文件使用 build。

从仓库根目录运行命令时，可以使用 examples/hello.es 作为示例源文件。编译后端所支持的目标平台由当前版本的编译器实现决定。

解释器与 AOT 生成程序忠实执行源码中的循环和输出，不设置执行步数、时间、迭代次数或输出行数上限，也不自动节流或中断。无限循环和持续输出会一直运行，直到操作系统终止进程或用户发送中断（SIGINT / Ctrl+C）。

命令参考

解释执行

easyscript debug example.es

读取并解释执行 example.es，适合快速运行和调试。

AOT 编译

easyscript build example.es

将源文件编译为可执行程序。成功后按 CLI 提示运行生成的程序；当前仓库的 AOT 后端目标是 Linux x86-64 ELF。

语法概要

程序入口

程序需要提供 int main() 入口。主函数内编写运行逻辑，并可使用 return code -> 0; 返回退出码。

int main() {
    return code -> 0;
}

变量赋值

使用 变量名 = 类型 -> 初始值 声明并赋值，例如：

i = int -> 1;

条件与循环

if 根据条件执行代码块；可添加 else 分支。while 在条件成立时重复执行代码块。

if (i > 0) {
            i = int -> i - 1;
} else {
    i = int -> 1;
}

while (i < 3) {
    i = int -> i + 1;
}

自定义函数

使用 def 定义函数。参数可标注类型或默认值，函数体由大括号包围。

def greet(name=std) {
    rules! write -> name
    rules! output -> a
}

标准库声明与链接

stdlib/ 是独立 Rust 动态库 crate，只实现 std::write、std::output、std::input 三个 IO 原语。只有执行 from library import std 时才触发加载；运行时优先校验脚本旁的 library/std.esh 与 library/libes_std.ess，任一缺失、读取失败或校验失败时再使用编译阶段嵌入编译器二进制的完整原始资源。嵌入的是声明与 tar 归档，不是 IO 实现代码。

// library/std.esh
// ===== EasyScript STD Standard Header ===== //
// Namespace : std
namespace std {
    extern std write -> es_std_write
    extern std input -> es_std_input
    extern std output -> es_std_output
}

声明文件中的 extern 仅将 EasyScript 名称映射到固定 ABI 符号，不写 def、rules! 或函数体。先独立编译目标平台的动态库，再用内置 libarchive 的打包工具创建归档；tar 根目录必须直接包含 libes_std.so 和 es_std.dll 两个文件。

        cargo build --manifest-path stdlib/Cargo.toml --release
        cargo run --manifest-path tools/std-package/Cargo.toml -- \
          stdlib/target/release/libes_std.so path/to/es_std.dll \
          examples/library/libes_std.ess

libes_std.ess 是 tar 归档，根目录直接包含 libes_std.so 和 es_std.dll。运行时只提取当前平台的文件并缓存；不调用外部 tar。运行环境需能加载 libarchive（Windows 使用 archive.dll）。

标准库 IO：std

导入 std 标准库后，优先使用 std.write() 和 std.output()。它们是标准库函数：write 将数据写入全局缓冲区，不立即打印；output 将当前缓冲区内容输出到控制台。

from library import std;

std.write("Hello");
std.output();

兼容简写 write(value) 和 output() 也合法，但不推荐省略 std. 前缀；优先写成 std.write() / std.output()，明确它们来自标准库并避免与自定义函数混淆。

rules! 语法糖

rules! IO 语句是标准库调用的语法糖，仍需先导入 std：

rules! std::write -> x

等价于调用 std.write(x)：写入全局缓冲区，不直接打印。

rules! std::output -> a

等价于调用 std.output(a)：输出缓冲区内容。参数保留旧语法的表达式求值行为。

rules! std::write -> "Hello from rules!"
rules! std::output -> a

终端单行输入

rules! std::input -> name 会阻塞等待终端输入一行，去掉行尾换行符，将结果作为字符串写入变量 name，并作为所在函数的返回值。示例中的目标参数 d 可以在调用时省略，所以调用形式是 input()；不需要提示语参数。

def input(d) {
    rules! std::input -> d
}

int main() {
    d = auto -> input()
}

自定义 println 函数

println 不是 std 内置函数。可用 def 定义普通 EasyScript 函数，在函数体中先调用 std.write，再调用 std.output：

def println(value=std) {
            rules! std::write -> value
            rules! std::output -> a
}

int main() {
    std.write("Hello");
    std.output();
    println("Also works");
}
重要提醒：请将 write 和 output 成对使用：先写入，再输出。单独调用 output 时没有新写入的缓冲区内容，可能触发隐藏逻辑 bug；当前实现会报告缓冲区尚未初始化。

完整示例：example.es

下面的程序用 def 自定义 println，基于标准库 std.write() 和 std.output() 输出，并展示 if/else 分支。

active system linux;
from library import std;

def println(value=auto) {
    std.write(value);
    std.output();
}

int main() {
    std.write("buffered output");
    std.output();
    i = int -> 1;
    if (i == 1) {
        println("condition matched");
    } else {
        println("condition did not match");
    }
    return code -> 0;
}
stop;

保存为 example.es 后，可用上方的 debug 命令解释执行，或用 build 命令进行 AOT 编译。
